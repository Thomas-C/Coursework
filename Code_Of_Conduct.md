# Team Code Of Conduct
This Code of Conduct defines the standards of behaviour expected from everyone in our team. 

The purpose of this is to create a professional and respectful environment which every member of the team can be productive and contribute effectively.

All members are EXPECTED to follow this Code of Conduct when working on the project, attending code reviews, communicating with the team and contributing to the repository.

## 1. Respect and Inclusion
Every team member should:
  - Treat eachother with respect and professionalism.
  - Hear people out when they are sharing their opinions even if you disagree.
  - Be Inclusive.
  - Not discriminate, harass or bully anyone.

## 2. Communication
Every team member should:
  - Communicate Respectfully and Honestly.
  - Respond within appropriate times (not last minute) and not ignore each other.
  - Keep relevant information avaliable to every team member.
  - Provide feedback when it is needed.
  - Raise problems if there is something wrong with the project.
  - Inform us if you can't attend any important Code Reviews.

## 3. Professional Responsibility
Everyone is responsible for making their own contribution to the project.

Everyone should:
  - Complete tasks within the given time frame. (if you cannot, speak to someone, they can help!!)
  - Take responsibility for your own work.
  - Double check your work before submitting.
  - Follow the project requirements.
  - Constantly work on your skills.
  - Avoid claiming knowledge that you don't actually know.

## 4. GitHub and Project Contributions
Everyone should agree on the workflow

These are: 
  - Participating in code reviews.
  - If an issue is found, creating and updating the issue is required.
  - Write meaningful commit messages (this is very important so we know what is going on!)
  - Not deleting or modifying other team members work.

## 5. Code Quality and Security
We have the responsibility to product software that is reliable and secure

Each member should:
  - Follow coding standards
  - Add Comments and Documentation.
  - Ensure your code is readable.
  - Report bugs as soon as they are found.
  - Not add malicious code on purpose.
  - Test before adding to branches.

## 6. Intellectual Property 
  - Respect Copyright and Licenses.
  - Follow license requirements.
  - Do NOT say another person's work is your own.

## 7. Attendance
  - Be prepared and ready to participate.
  - Allow everyone to speak, do not interrupt anyone
  - Inform someone ASAP if you cannot attend!!

## 8. Reporting Misconduct
You should report serious misconduct or behaviour that can effect the team negatively.

These include:
  - Bullying or Harrassment.
  - Discrimination.
  - Sabotage.
  - Breach of Confidentiality.

This code of conduct applies to everyone who is taking part in the project and this will be updated if the team agrees on changes.
