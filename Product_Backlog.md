Aim of the project = to build a program that can generate SQL queries from a small database.

Requirement 1 Setup the database

The database should be set up via the use of the IntelliJ development environment which should be connected to a GitHub repository and should be able to run SQL queries. A doctor file should also be created in order to manage and deploy docker containers.

This requirement is completed when the program can connect to the clients database without returning errors

Requirement 2 Population of a district

This query should generate the answer to the population of a given city and must include the following  the City name District and it's Population

This requirement is completed when the query returns successfully with the right information for the city

Requirement 3 Population of a city
This query should generate the answer to the population of a given city and must include the following  the City name country District and it's Population

Requirement 4 county report
A report based off the data should be generated with these headings
Code
Name
Continent
Region
Population
Capital

Requirement 5 city report
A report based off the data should be generated with these headings
Name.
Country.
District.
Population.

Requirement 6 Population report
The name of the continent/region/country.
The total population of the continent/region/country.
The total population of the continent/region/country living in cities (including a %).
The total population of the continent/region/country not living in cities (including a %).
